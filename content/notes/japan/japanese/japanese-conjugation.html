## 07｜普通形不是只有辭書形

先決定肯定／否定、非過去／過去，再檢查右側句型；普通形是一整套系統。

編輯解析

動詞的 行く／行かない／行った／行かなかった 都是普通形；辭書形只是一種非過去肯定形。所以「普通形＋の」不等於只能 行くの，也有 行ったの、行かないの。

同一句可以「內層普通形＋外層丁寧形」：日本へ行ったことがあります。但別把「所有句內都只能普通形」當總規則；原因 から／ので 也能接丁寧形，直接引語也可保留禮貌語尾。

普通形不是只用於隨便說話；它是從句、名詞修飾、原因、傳聞與思考句型的基本零件。

食べない與食べません

形式 語體 典型位置
食べない 普通形 普通體句尾；或嵌入其他結構
食べません 丁寧形 禮貌地結束完整句子
今日は朝ご飯を食べません。 今天不吃早餐。
朝ご飯を食べないとき、薬を飲みません。 不吃早餐時，不服藥。
易錯點 · RISK A 食べませんとき不成立

とき 是名詞，前面的動詞句要用普通形修飾：食べないとき。

普通形四格

詞類 非過去肯定 非過去否定 過去肯定 過去否定
動詞 行く 行かない 行った 行かなかった
い形容詞 高い 高くない 高かった 高くなかった
な形容詞 静かだ 静かではない 静かだった 静かではなかった
名詞 休みだ 休みではない 休みだった 休みではなかった

ある的特殊否定

丁寧形 普通形
あります ある
ありません ない
ありました あった
ありませんでした なかった
易錯點 · RISK A 不是「あらない」

時間がありません -> 時間がない -> 時間がないから行きません。

句內普通形，句尾丁寧形

句子 內層 外層
日本へ行ったことがあります。 行った：經驗內容的普通形。 あります：丁寧形。
リンさんが昨日買った本を読みました。 買った：修飾本的關係子句。 読みました：主句過去丁寧形。

這幾組接續的だ不能漏

学生だから 因為是學生
学生だと思います。 我想是學生。
学生だそうです。 聽說是學生。
静かだから 因為安靜
簡単だそうです。 聽說很簡單。

備註 這裡針對から／と思う／傳聞そう等表內結構。不是所有右側句型都一律保留だ；ので、でしょう等請看接續總表。

原手冊頁：P25、P26

相關主題：接續總表：だ／な／の／不加だ · から／ので／ため：理由、語體與語氣 · と思う／と言う／ように言う

## 08｜い形、な形、名詞：三套接續

きれい 雖然以 い 結尾，仍按な形容詞處理；いい 的活用用 よい 系列。

編輯解析

先判詞類，再做變化：高い → 高くない／高かった／高くて／高くなる；静か → 静かではない／静かだった／静かで／静かになる。

よくない 是 いい 的否定；悪い 是另一個詞。静かに話す 是用な形容詞修飾動作；先生に聞く 的 に 卻是人物對象，不應把所有「Nに」都叫副詞化。

先判斷是い形容詞、な形容詞或名詞；不能只看字尾。

い形容詞

功能 高い的形式 例
現在否定 高くないです この店は高くないです。
過去肯定 高かったです 昨日は高かったです。
過去否定 高くなかったです 前は高くなかったです。
連接 高くて 山が高くて、きれいです。
修飾動詞 高く／薄く 値段を高くする。／薄く切る。
變化 高くなる／高くする 値段が高くなる／値段を高くする

いい的不規則活用

肯定 否定 過去 過去否定 連接
いい よくない よかった よくなかった よくて
易錯點 · RISK C いい不是「いくない」

× いくない／いいくて；○ よくない／よくて。

な形容詞

功能 静か的形式
現在否定 静かではありません
過去肯定 静かでした
修飾名詞 静かな町
連接 静かで
修飾動詞 静かに
變化 静かになる／静かにする

きれい是な形容詞

きれいな部屋

乾淨／漂亮的房間

きれいではありません。 不乾淨／不漂亮。
きれいに並べます。 整齊地排列。
きれいになりました。 變乾淨了。
易錯點 · RISK B い形容詞不能接じゃありません

× 高いじゃありません；○ 高くないです。

じゃありません／ではありません 主要接名詞與な形容詞。

並列連接

詞類 連接形式 例
動詞 Vて 朝ご飯を食べて、学校へ行きます。
い形容詞 〜くて この部屋は広くて明るいです。
な形容詞 〜で この町は静かで便利です。
名詞 〜で 父は会社員で、母は先生です。
備註 な形容詞／名詞的で不是場所助詞

這裡的 で 是 だ 的連接形式，功能是把兩個述語連起來。

原手冊頁：P27、P28、P90

## 09｜動詞活用：て形、た形與補充詞彙

把動詞類別先判對，再套音便；不要把所有 る 結尾都當一段。

編輯解析

着る 是一段，切る／帰る／始まる／泊まる 是五段。行く 的て形／た形是特例 行って／行った。来る 還會因活用改變讀音：くる、きます、こない、きた。

Vたほうがいい、Vた後で、Vたことがある 都用た形，但功能分別是建議、相對完成與經驗；活用形相同，不代表整句語意相同。

て形與た形共享同一套音便；看到た不代表整句一定是過去。

五段動詞音便

辭書形結尾 て形 た形 例
う・つ・る って った 帰る -> 帰って -> 帰った
む・ぶ・ぬ んで んだ 飲む -> 飲んで -> 飲んだ
く いて いた 書く -> 書いて -> 書いた
ぐ いで いだ 泳ぐ -> 泳いで -> 泳いだ
す して した 話す -> 話して -> 話した
易錯點 · RISK B 行く是特例

行く -> 行って -> 行った，不是 行いて／行いた。

一段與不規則

類型 變化
一段 食べる -> 食べて -> 食べた／見る -> 見て -> 見た
する する -> して -> した
来る 来る -> 来て -> 来た
複合 持って来る -> 持って来て -> 持って来た

来る・着る・切る

辭書形 ます形 て形 た形
来る（くる） 来ます（きます） 来て（きて） 来た（きた）
着る（きる） 着ます（きます） 着て（きて） 着た（きた）
切る（きる） 切ります（きります） 切って（きって） 切った（きった）
易錯點 · RISK B 着る是一段，切る是五段

同樣讀 きる，但 着る -> 着て；切る -> 切って。

把手寫頁中的動詞放回同一張活用表

辭書形 ます形 ない形 て形／た形
住む 住みます 住まない 住んで／住んだ
泊まる 泊まります 泊まらない 泊まって／泊まった
始まる 始まります 始まらない 始まって／始まった
出かける 出かけます 出かけない 出かけて／出かけた
出る 出ます 出ない 出て／出た
帰国する 帰国します 帰国しない 帰国して／帰国した
風邪をひく 風邪をひきます 風邪をひかない 風邪をひいて／風邪をひいた
無理をする 無理をします 無理をしない 無理をして／無理をした

備註 上表的動詞來自手寫筆記與既有整理；把四種活用排在一起是本版的編輯補全，不是手寫筆記的逐格抄錄。

## 10｜自他動詞、なる／する、ようになる

一件事發生變化，和某人把它改變，是兩種敘述視角。

編輯解析

授業が始まる 描述課開始；先生が授業を始める 描述老師開始上課。なる 描述主體變成某狀態，不保證變化完全沒有人的介入；する 則把使其改變的行為放到前景。

動詞表達新的能力、習慣或狀態時，用 ようになる：日本語が話せるようになる 是能力變化；早く起きるようになる 是習慣改變。它不必然表示「慢慢」；是否漸進須看上下文。

先判斷是「某物自己進入狀態」還是「某人對某物施加動作」。

Nが + 自動詞　／　人が Nを + 他動詞

自動詞 他動詞 對比
ドアが開く ドアを開ける 門開了／把門打開
ドアが閉まる ドアを閉める 門關了／把門關上
電気がつく 電気をつける 燈亮了／開燈
電気が消える 電気を消す 燈熄了／關燈
授業が始まる 先生が授業を始める 課開始／老師開始上課
予定が決まる 予定を決める 行程定下來／決定行程

工作結束與做工作

句子 焦點
仕事が終わった後で帰ります。 工作這件事結束後回去。
仕事をした後で帰ります。 做了工作後回去；焦點在「我做工作」。

なる與する

自然／主體變化：なる 人為使之改變：する
暖かくなる 部屋を涼しくする
医者になる 字を大きくする
上手になる 部屋をきれいにする
値段が10円になる 値段を10円にする
易錯點 · RISK B 名詞＋に不等於「副詞化規則」

な形容詞變副詞是 静かに話す；名詞後的 に 多半是格助詞或結果：半分に切る、先生に聞く。

要る・入る・いる・入れる：詞義與格框架一起看

動詞／類型 讀音 基本框架 來源例與意思
要る・五段 いる 必要な物が要る 親子丼を作るのに、しょうゆが要ります。
需要醬油。
入る・五段 はいる 物／人が場所に入る しょうゆが容器に入ります。
醬油進入容器。
いる・一段 いる 人／動物が場所にいる 台所に母がいます。
媽媽在廚房。
入れる・一段 いれる 人が物を場所に入れる 料理にしょうゆを入れます。
把醬油加入料理。

備註 要る 的丁寧形是要ります；存在的いる是います。しょうゆが入れます 應依原意改為 しょうゆを入れます；しょうゆがいます 應依原意選 しょうゆがあります 或 しょうゆが要ります。

同頁的詞彙搭配

正確形式 分析 陷阱
簡単な料理 な形容詞 + な + 名詞。 上手 通常評價人或技能，不自然地直接評價一道料理。
四歳になる 年齡 + に + なる，表示「滿四歲」。 四個／四冊 是其他量詞，不能代替年齡。
めがねをかけている 戴眼鏡後的結果狀態。 不是 はく／かぶる／着る。
靴を脱いで、うちに入る 鞋是 脱ぐ 的受詞；家是 入る 的到達點。 靴を取る 不是一般「脫鞋」的標準搭配。
要表達的變化 形式 例
性質改變 い形：～くなる 寒くなりました。
狀態改變 な形：～になる 元気になりました。
身分改變 N＋になる 先生になりました。
能力形成 可能表現＋ようになる 日本語が話せるようになりました。
習慣形成 Vる＋ようになる 毎朝早く起きるようになりました。

備註 接續提示：✕ 話すになる → ○ 話すようになる。要說「變得會說」則用 話せるようになる；兩者不是同一句。

## 11｜ている：進行、習慣與結果狀態

不要把 ています 一律譯為「正在」；先看動詞本身的事件類型。

編輯解析

飲んでいます 常是動作正在進行；住んでいます 是居住狀態；めがねをかけています 通常是戴上之後持續戴著。外形同樣是ている，解讀卻不相同。

服裝動詞應整組記住：帽子をかぶる、めがねをかける、シャツを着る、ズボンをはく。先選對動詞，再決定要描述穿戴動作或穿戴狀態。

ています可表示正在進行、反覆活動，以及動作完成後留下的持續狀態。

功能 例 判斷
正在進行 今、コーヒーを飲んでいます。 動作正在展開
反覆／職業 日本語を教えています。 持續從事
結果狀態 緑のズボンをはいている人 穿上後維持
居住／姿勢 日本に住んでいます。／立っています。 狀態持續

服裝動詞不能全部用着る或はく

物品 基本動詞 狀態
帽子 帽子をかぶる 帽子をかぶっている
めがね めがねをかける めがねをかけている
ネクタイ ネクタイをする ネクタイをしている
シャツ・コート・スーツ・着物 〜を着る 〜を着ている
ズボン・スカート・靴 〜をはく 〜をはいている
姿勢 立つ／座る 立っている／座っている
易錯點 · RISK B 帽子をはいています不成立

帽子使用 かぶる；下半身與鞋使用 はく。

辨析 「正在穿」與「穿著」

シャツを着ています 通常表示已穿上並維持穿著，不是每次都等於手正在套衣服。

## 12｜てしまう：完成與非預期

遺憾是常見語境，不是 てしまう 必然自帶的負面意義。

編輯解析

全部読んでしまう 可強調做完；財布を忘れてしまった 才常因事件本身而帶出後悔。口語縮約要保留原て形的清濁：てしまう → ちゃう，でしまう → じゃう。

同一形式可強調徹底完成，也可配合語境表達非預期、遺憾或不可逆。

功能 例 語感
完成／做到底 この本を全部読んでしまいます。 把整本讀完；不一定負面
非預期／遺憾 財布を電車に忘れてしまいました。 不小心忘了
不可逆 寝坊してしまいました。 事情已經發生

口語縮約

原形 口語 例
〜てしまう 〜ちゃう 食べてしまう -> 食べちゃう
〜てしまった 〜ちゃった 忘れてしまった -> 忘れちゃった
〜でしまう 〜じゃう 読んでしまう -> 読んじゃう
〜でしまった 〜じゃった 飲んでしまった -> 飲んじゃった
易錯點 · RISK B 読んちゃった不是正確縮約

原本是 読んでしまった，所以縮為 読んじゃった。

// 13 · 活用與接續

## 13｜てくる／ていく：基準點與方向

同時看「哪裡是這邊」與「哪個時點是現在」，再理解來／去。

編輯解析

買いに来る 是為了購買而來；買ってくる 常是去買後回到基準點。前者的 に 是移動目的，後者的 てくる 把動作放進返回／朝向基準點的框架。

分かってきた 將變化連到現在，勉強していく 將活動延伸到未來。這是一種方向關係，不是 てくる＝逐漸、ていく＝持續 的一對一翻譯。

核心不是單純「來／去」，而是相對於說話者、現在或基準點的方向。

空間方向

形式 方向 例
持ってくる 帶到說話者／基準點這邊 この本を持ってきてください。
持っていく 從基準點帶往別處 傘を学校へ持っていきます。
買ってくる 去買並回來／帶回 パンを買ってきます。
行ってくる 去後再回來 ちょっと行ってきます。

時間方向

過去 ─────→ 現在：〜てくる　／　現在 ─────→ 未來：〜ていく

日本語が少しずつ分かってきました。 日文到現在逐漸懂了。
これからも勉強していきます。 今後會繼續學下去。
知らない人が話しかけてきました。 陌生人朝我搭話。

買いに来る與買ってくる

形式 意思
買いに来る 為了買而來；に是移動目的
買ってくる 去買後回到基準點／把東西帶回來
買ってきたもの 買回來的東西；前項是關係子句
易錯點 · RISK B てくる＝逐漸、ていく＝持續是過度簡化

真正核心是相對基準點的方向；空間、時間與動作指向都能使用。

最常見的語境是「我去問一下，問完再回來」。它不是一整塊固定片語，而是 ちょっと + 聞いて + きます 的組合。

成分 功能
ちょっと 「一下、稍微」；也會柔化語氣，使行動聽起來較輕、較短。
聞いて 聞く 的て形。依語境可表示「問」或「聽」。
きます Vてくる：離開目前位置去做 V，然後回到這裡／回到基準點。

目前位置「我在這裡」→去問 -> 問完 -> 回來

省略的成分由語境補出

（私は）先生に　ちょっと聞いてきます。（我）去問老師一下再回來。

（私は）受付で　ちょっと聞いてきます。（我）去櫃檯問一下再回來。

四句最小對比

形式 核心語感
ちょっと聞きます。 問一下／聽一下；沒有移動與返回資訊。
ちょっと聞いてみます。 試著問問看；重點是嘗試。
ちょっと聞きに行きます。 為了詢問而去；重點是移動目的，沒有明確編碼「回來」。
ちょっと聞いてきます。 去問一下再回來；重點是往返與動作完成。

易錯點 聞いてきます 的 きます 不是「聽見某事來了」，而是把整個 聞く 動作放在「離開 -> 執行 -> 返回」的方向框架中。語境 若前文是在談音樂，聞いてきました 也可能是「去聽過後回來了」。單獨說 ちょっと聞いてきます 時，日常會話通常優先理解為「去問一下」。
