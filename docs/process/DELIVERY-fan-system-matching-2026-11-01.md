# 電腦風扇整合筆記

## 範圍與結果

- 新增三語 `/{locale}/note/hardware/computer/fan-system-matching/`，整理七份研究稿為一篇筆記；保留既有分類與 Moonlit Vim 樣式。
- 原先退役的 `140mm-case-fans` 路徑仍回傳 404，沒有復活舊內容或新增轉址。
- 40 筆核心型號／模式、368 組有效掃描，另加兩組高速模式，共 370 條曲線、2,960 個點。13 組隔離掃描不進計算。資料來源為 Cybenetics；不是本站量測。
- 公開資料採欄位白名單，只保留報告識別、公開網址、模式、設定與數值；沒有私人附件識別、工作區路徑或原稿程式碼。
- 實測轉錄曲線只作有界分段線性內插，保留負壓與非單調區間，不外插、不補造零壓端點、不按 RPM 縮放。
- 另設明確標示的假想模型。系統阻抗預設關閉、K 空白；不能把它當作 Pop XL Silent 實測，也不輸出產品購買排名或硬體控制。
- 語言審閱逐項對照原文結構、數值、公式、模式識別與來源連結；英文與日文由代理翻譯並對照審閱，不宣稱人工審閱。

## 重要內容修正

三組原稿 K 都是示範值，不是機殼量測。來源設定不改稱 BIOS PWM；A120 FC Low／High 模式不合併。摘要端點不冒充同一工作點。過期價格不當現價。原廠安全／最大電流與整組負載要分開核對；S12038-4K 不沿用零售商的全面主機板禁用說法。

## 封面與相容性

封面為原創幾何風扇、格柵氣流與抽象 P–Q 交點示意，不代表品牌產品或量測圖；WebP 與 JPEG 衍生圖已檢視。

依擁有者不新增雜湊的要求，新封面登錄 `sha256: null`。產物檢查僅在既有雜湊非空時執行原有雜湊比較，仍檢查尺寸、位元組數、路徑及發布歸屬。既有素材紀錄未改動；測試限制空值只能出現在本次原創封面，另修正 JPEG fixture 的聯集型別推導，沒有放寬其他規則。
