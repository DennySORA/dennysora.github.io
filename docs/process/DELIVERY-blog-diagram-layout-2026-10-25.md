## 問題與範圍

擁有者回報翻譯架構文章的第三條泳道超出閱讀欄。公開頁面在隔離雲端瀏覽器
1180 × 757 的量測：閱讀區 738px、HTML 畫布 960px，圖高 1552／1720px；
其他六張 SVG 仍有 880px 最小寬度。原圖可橫捲，但初始畫面無法呈現全貌。

- HTML 圖以維持原始座標的等比縮放符合閱讀欄，縮放同時參與版面計算，
  不留下原高度的空白；容器改寬時重新計算。
- 翻譯、P2P 架構、P2P 隱私的 SVG 移除超出閱讀欄的強制最小寬度。
  密碼管理器文中的 SVG 是圖示，沒有相同寬圖問題，未更動。
- 圖片標題新增三語「放大閱讀／顯示全圖」，放大只在圖的既有捲動區內進行；
  保留鍵盤焦點、SVG 下載、原本互動與無 JavaScript 時的可讀橫捲備援。
- 十二份文章 HTML 與已發布提交逐位元組相同；未改寫正文、圖上數值、配色、
  目錄欄、來源或既有互動模型。沒有依賴、鎖檔或工作流程變更。
