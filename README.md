# dennysora.github.io

李汶道 (DennySORA) — personal resume site, hosted on GitHub Pages.

**Live:** https://dennysora.me

- Trilingual: 繁體中文 / English / 日本語 (auto-detects browser language, choice persisted across pages)
- `/` — one-page resume (skills, experience, education)
- `/detail/` — technical profile directory
  - `/detail/depth/` — technical depth, engineering principles, working style
  - `/detail/research/` — R&D log (trilingual LLM, adaptive transformer, speech evaluation)
  - `/detail/production/` — production engineering evidence
  - `/detail/about/` — beyond engineering, open-source projects, communities, notes
- `style.css` / `lang.js` / `site.js` — shared design system, trilingual switcher, motion (scroll progress + reveal)
- `assets/` — logo, avatar, favicon (web-optimized + original archive)
